# Описание тестов

| Название | Тип | Компоненты | Предусловия |
| --- | --- | --- | --- |
| Happy path | e2e | Orchestrator, Payment Service, FraudCheck | Все сервисы доступны, у пользователя достаточно средств на счете, проверка на мошенничество вернет ОК |
| Недостаток средств | e2e | Orchestrator, Payment Service | У пользователя недостаточно средств на счете |
| Блокировка подозрительной транзации автоматизированной проверкой | e2e | Orchestrator, Payment Service, FraudCheck | FraudCheck возвращает Declined на транзакцию пользователя |
| Ручная проверка, неудача | e2e | Orchestrator, Payment Service, FraudCheck, эмуляция работы эксперта, совершающего ручную проверку | FraudCheck перенаправит запрос на ручную проверку, ручная проверка вернет Declined |
| Ручная проверка, успех | e2e | Orchestrator, Payment Service, FraudCheck, эмуляция работы эксперта, совершающего ручную проверку | FraudCheck перенаправит запрос на ручную проверку, ручная проверка вернет Approved |
| Ручная проверка, таймаут | e2e | Orchestrator, Payment Service, FraudCheck, эмуляция работы эксперта, совершающего ручную проверку | FraudCheck перенаправит запрос на ручную проверку, ручная проверка закончится таймаутом, что приведет к Approve (можно настроить моментальный таймаут) |
| Старт транзакции (ретраи + идемпотентность) | integration | Payment Service | Клиент посылает запрос на создание платежа |
| Отправка запроса на антифрод проверку (ретраи + идемпотентность) | integration | FraudCheck Service | Отправка существующей транзакции на проверку |
